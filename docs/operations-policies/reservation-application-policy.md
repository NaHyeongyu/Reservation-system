# 예약 신청 정책

## 목적

중복 신청과 잘못된 신청을 막고, 공개 신청 흐름을 일관되게 유지합니다.

## 기본 정책

- 같은 파티에는 한 사람당 한 번만 신청할 수 있습니다.
- 중복 여부는 `전화번호` 기준으로 판단합니다.
- 이미 같은 파티에 `pending`, `confirmed`, `waitlisted` 상태가 있으면 같은 전화번호로 다시 신청할 수 없습니다.

## 신청 시 필수 입력값

- 이름
- 생년 4자리
- 인스타그램 ID
- 전화번호
- 성별
- 은행명
- 계좌번호

## 저장되는 주요 값

- 신청자 이름
- 신청자 생년
- 신청자 인스타그램 ID
- 신청자 전화번호
- 신청자 성별
- 은행명
- 계좌번호
- 신청 시각

## 신청 제한 정책

- 파티 시작 시간이 지난 경우 신청할 수 없습니다.
- 필수 동의값이 없으면 신청할 수 없습니다.
- 유효하지 않은 생년 4자리 형식이면 신청할 수 없습니다.
- 유효하지 않은 인스타그램 ID 형식이면 신청할 수 없습니다.
- 유효하지 않은 전화번호 형식이면 신청할 수 없습니다.

## 현재 미지원 정책

- 한 번에 여러 명 예약
- 같은 사람이 복수 예약
- 입금 상태별 자동 분기
