# 파티 운영 정책

## 목적

파티 등록, 수정, 삭제, 정원 운영 규칙을 통일합니다.

## 파티 생성 입력값

- 파티명
- 날짜
- 시작 시간
- 종료 시간
- 남자 정원
- 여자 정원
- 프론트 노출 여부
- 인원 수 노출 여부

## 파티 생성 규칙

- 한 날짜에는 파티 1개만 생성할 수 있습니다.
- 종료 시간은 시작 시간보다 뒤여야 합니다.
- 남자 정원과 여자 정원의 합이 전체 정원으로 취급됩니다.

## 수정 규칙

- 파티명, 날짜, 시간, 남녀 정원을 수정할 수 있습니다.
- 현재 참가 인원보다 적은 정원으로는 줄일 수 없습니다.
- 같은 날짜에 다른 파티가 이미 있으면 수정할 수 없습니다.

## 삭제 규칙

- 예약 내역이 있는 파티는 삭제할 수 없습니다.
- 예약이 없는 파티만 삭제 가능합니다.

## 참가 처리 규칙

- 관리자는 신청자 또는 대기자를 참가자로 바꿀 수 있습니다.
- 해당 성별 남은 좌석이 없으면 참가 처리할 수 없습니다.
- 남자 좌석이 없으면 남자 신청자의 `참가` 버튼은 비활성화됩니다.
- 여자 좌석이 없으면 여자 신청자의 `참가` 버튼은 비활성화됩니다.

## 운영 주의사항

- 현재 대기자 자동 승격은 없습니다.
- 누군가 취소해도 운영자가 직접 대기자를 참가자로 바꿔야 합니다.
