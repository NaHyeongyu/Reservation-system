# 공개 노출 정책

## 목적

프론트에서 사용자에게 어떤 파티와 어떤 정보가 보이는지 통제합니다.

## 파티 노출 규칙

- `published` 상태인 파티만 공개 화면에 노출됩니다.
- `draft` 상태 파티는 공개 화면에 노출되지 않습니다.
- `closed`, `cancelled`, `completed` 파티는 일반 공개 신청 대상이 아닙니다.

## 인원 수 노출 규칙

- 파티별로 `인원 수 노출 / 비노출`을 설정할 수 있습니다.
- 공개 화면에서 남녀 신청 현황을 보여줄지 말지 이 설정으로 결정합니다.

## 공개 화면 안내 규칙

- 같은 성별 정원이 차면 해당 성별에 대해 `대기자 신청` 안내를 노출합니다.
- 신청서 화면에서도 성별 선택 후 대기 접수 예상 시 안내 문구를 보여줍니다.
- 신청 완료 후 실제 저장 결과가 `waitlisted`면 완료 화면에서 대기 접수 문구를 보여줍니다.

## 메타데이터

- 현재 서비스 타이틀: `지문인식 예약 신청 서비스`
- 앱 아이콘은 `jimoon_logo.png` 기반으로 사용합니다.

## 운영 주의사항

- 파비콘은 브라우저 캐시 영향이 커서 배포 후 바로 안 바뀌는 것처럼 보일 수 있습니다.
- 공개 화면 문구 변경 시 신청서, 목록, 완료 화면을 같이 확인해야 합니다.
