# 정원 및 대기자 정책

## 목적

남녀 정원을 분리 운영하고, 신청 집중 시 대기자를 일관되게 관리합니다.

## 정원 기준

- 전체 정원보다 `남자 정원`, `여자 정원`이 우선입니다.
- 남자는 `male_capacity` 기준으로 판단합니다.
- 여자는 `female_capacity` 기준으로 판단합니다.

## 정원 계산에 포함되는 상태

- `pending`
- `confirmed`
- `completed`

## 정원 계산에서 제외되는 상태

- `waitlisted`
- `cancelled`
- `rejected`
- `no_show`

## 대기자 전환 규칙

- 신청 시점에 해당 성별의 `신청 + 참가` 수가 정원에 도달하면 `waitlisted`로 저장합니다.
- 총 정원이 남아 있어도 해당 성별 정원이 찼으면 대기자로 전환됩니다.

예시
- 남자 정원 10명
- 현재 남자 `pending 4`, `confirmed 5`, `completed 1`
- 합계 10명
- 다음 남자 신청은 `waitlisted`

## 선착순 경쟁 규칙

- 신청 저장은 DB 함수에서 원자적으로 처리합니다.
- 사용자가 신청서를 작성하는 동안 다른 사람이 먼저 들어오면, 늦은 신청자는 자동으로 `waitlisted` 될 수 있습니다.
- 완료 화면에는 대기 접수 안내가 노출됩니다.

## 공개 화면 표시 규칙

- 남자 정원이 차면 `남 대기자 신청`
- 여자 정원이 차면 `여 대기자 신청`
- 둘 다 차면 두 안내가 함께 노출될 수 있습니다.

## 현재 미지원 정책

- 대기자 자동 승격
- 취소 발생 시 자동 재배정
- 성별별 대기 순번 자동 조정 알림
