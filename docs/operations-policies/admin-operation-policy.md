# 관리자 운영 정책

## 목적

메인 관리자와 지점 관리자의 권한 범위를 분리하고 운영 책임을 명확히 합니다.

## 관리자 역할

- `super_admin`
- `branch_admin`

## 메인 관리자 권한

- 전체 지점 조회
- 지점 생성
- 지점 상세 조회
- 지점 관리자 계정 생성
- 전 지점 운영 현황 확인

## 지점 관리자 권한

- 본인에게 연결된 지점만 조회 가능
- 캘린더 조회
- 파티 조회 및 생성
- 파티 상세 운영
- 지점 설정 조회 및 수정

## 접근 범위 정책

- 지점 관리자는 본인 지점 데이터만 접근 가능합니다.
- 메인 관리자는 모든 지점 데이터 접근이 가능합니다.

## 운영 화면 기준

- 대시보드: 현재 처리할 신청과 대기자 우선 확인
- 캘린더: 날짜별 파티 운영 현황 확인
- 파티 상세: 신청자, 대기자, 참가자 직접 처리
- 지점 관리: 메인 관리자 전용

## 현재 운영상 중요한 제한

- 입금 확인 자동화 없음
- 대기자 자동 승격 없음
- 상태 변경 로그 별도 저장 없음

## 운영 권장 방식

- 신청자와 대기자는 오래된 순으로 확인
- 취소 발생 시 대기자를 수동으로 참가 처리
- 파티 시작 직전에는 `pending` 상태를 우선적으로 정리
